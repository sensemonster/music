KEY SLIDE RULE - Designed by Martin Kendall
===========================================

Find the flats or sharps in any major key. Fully offline, no account, no tracking.

Quickest way (no hosting, any computer)
---------------------------------------
Double-click index.html. It opens in your browser and works without internet.

Install it as an app on phones, tablets and Mac
-----------------------------------------------
Phones and tablets only allow app-style installs from a secure web address, so put
this folder on any static host once, open the address, and install. After that first
visit it runs fully offline from the device and never needs the host again.

Free hosts (drag and drop the folder):
  - Netlify Drop        https://app.netlify.com/drop
  - Cloudflare Pages    https://pages.cloudflare.com
  - GitHub Pages        https://pages.github.com

Then, on each device, open the address once while online:
  iPhone / iPad (Safari)   Three-dot menu next to the address bar, Share, then
                           Add to Home Screen. Leave Open as Web App on. If the
                           option is missing, use Edit Actions in the Share menu.
  Android (Chrome)         Menu, then Install app (or Add to Home screen)
  Mac (Safari)             File, then Add to Dock (needs macOS Sonoma 14 or later)
  Mac (Chrome or Edge)     Install icon in the address bar

Menu names vary a little between versions.

Updating: change the files, then bump CACHE in sw.js (key-slide-rule-v3 to -v4) so
installed copies pick up the new version.

Files
-----
index.html, manifest.webmanifest, sw.js, and the icon PNGs. Fonts are your device's
own, so nothing is downloaded.
