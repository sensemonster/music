Key Slide Rule - Designed by Martin Kendall

Tap on the target key to reveal the key signature.

Target key

E♭ major

Flat order · B E A D G C F

Sharp order · F C G D A E B

The rule

Flats run along B E A D G C F up to the target note, plus the next one.

Sharps run along F C G D A E B and stop two places before the target.

F major is the exception: one flat, B♭.

Opened from a file, this works offline as it is. To install it as an app on a phone or tablet, upload the whole folder to a web host first. The README explains how.
